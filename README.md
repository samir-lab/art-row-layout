# art-row-layout

## Install
```
npm install art-row-layout
```
## Usage
```
import ArtRowLayout from 'art-row-layout'
import 'art-row-layout/dist/art-row-layout.css'
Vue.use(ArtRowLayout)
```

```
<art-row :gutter="20">
    <art-col :span="24"></art-col>
    <art-col :span="24"></art-col>
</art-row>
```
